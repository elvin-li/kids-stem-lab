01 色彩与对比度

学科色在全站是语义化的：同一个颜色永远代表同一个学科，不能拿来做装饰。 无论家长页采用浅色背景，还是其他主题切换背景层级，文字与底色都必须成对核对，所以每个组合都实测。

02 字号

标题用 clamp() 随视口缩放，所以右侧的 px 是当前窗口宽度下的实测值，改变窗口大小数字会变。 正文行高统一 1.65，中文小字在浅色或深色背景上都要保持清楚、舒展。

已知取舍：站点的字号是按内容需要逐个定的，不是严格的模块化比例（1.125 或 1.25 的等比数列）。 好处是每处都合适，代价是新增页面时没有唯一正确答案——照抄这页上最接近的用途即可。

03 圆角与尺度

圆角是唯一被 token 化的尺度。触控目标统一 44px 最小高度，已经写进 base.css 的 .btn / .chip / .input / input[type=range]。

已知缺口：间距（padding / gap）没有 token，全站是 4 / 8 / 10 / 12 / 14 / 16 / 18 / 24 / 32 / 44 / 64 这些字面值混用。 短期不改是为了避免一次性重排全站；新增样式请从这串数里挑，不要引入 13px、21px 这类孤立值。

04 组件

下面每一个都是活的真实组件。用 Tab 走一遍就能看到全站统一的焦点环。

焦点环：由 base.css 的 :focus-visible 统一提供，2px 实线 + 3px 外偏移， 用的是当前 --accent。任何组件都不许写 outline: none 而不给替代焦点样式。 按 Tab 从本页顶部走一遍即可核对。

05 童趣层

给孩子的那一层。故意不做连胜、排行榜、金币和倒计时——这些会把注意力从「想明白」拉到「别断」。 贴纸只标记「你去过、你做完了」，是收藏册而不是计分板。

分龄与动效：html[data-playful-age] 只调整提示密度和字号，从不隐藏核心任务—— 小孩子看到的是同一个实验，不是删减版。用户在足迹页选「减少动效」会写 html[data-playful-motion="reduced"]，与系统 prefers-reduced-motion 走同一套降级。

06 插图库

全站插图只有一个来源：assets/js/illustrations.js。下面这份目录是页面打开时从 ILLUSTRATIONS.artNames() 现场读出来的，所以库里加一张、改一张，这里就跟着变—— 要找现成的图先在这里翻，别再往页面里贴新的 emoji 或一次性 SVG 片段。

插图目录需要浏览器执行脚本，本段由 illustrations.js 现场生成。

画新图之前先读这三条：视觉主体留在中心安全区（slice 图位会裁掉溢出的一边）； 颜色用具体色值而不是 currentColor，因为同一张图会同时出现在浅底和深底上； 每张都要写 title 和 desc，那是读屏用户唯一能拿到的画面描述。

07 无障碍约定

这些不是建议，是 tools/check-contract.mjs 和 tools/verify.mjs 会在真实 Chrome 里逐页检查的硬条件。

  • 每页恰好一个 h1，一个 main landmark，一条指向本页真实 id 的跳到主要内容链接。
  • 固定六项主导航，链接目标固定，aria-current="page" 恰好一个。
  • 所有可交互控件必须有可访问名称：文字内容、aria-label、或关联的 label。
  • 状态永不只靠颜色：完成态同时给 ✓ 和文字，按下态同时给 aria-pressed。
  • 动态变化用 aria-live / role="status" 播报，不静默改 DOM。
  • 触控目标最小 44px；键盘可达顺序与视觉顺序一致。
  • 尊重 prefers-reduced-motion，并额外提供页内开关。
  • 不用 alert() / confirm()——破坏性操作走页内两步确认。
  • 不引外部 CDN、字体或 JS 库；全站在 file:// 双击即开。
  • 不做连胜、排行榜、完成百分比；不要登录，不上传任何数据。
本页的色值、对比度与字号均由浏览器实时从 assets/css/base.css 计算得出，因此与线上样式不可能不一致。 对比度按 WCAG 2.1 相对亮度公式计算；数值达标不等于整体无障碍达标，键盘与读屏仍需人工走查。
