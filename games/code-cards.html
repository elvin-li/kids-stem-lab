编程5–9 岁约 10 分钟

排错一张，海龟会自己改路吗？

不插电指令卡把「程序=按顺序执行」做成可触摸的序列：向前走、左转、右转只改朝向，排错一张卡结果就会错——调试就是对照目标找差异再改一条。本页练顺序、方向与迭代；不在行走路径上放障碍物绊倒，不拿尖锐物当「机器人」。

学什么：密码是「符号→意思」的对应表；猜对规则才能解码，不是把图案当装饰。

指令条（点一张可拿掉）

先猜一猜，再跑

第 1 题：卡片顺序是「前进、左转、前进」。若把前两张对调成「左转、前进、前进」，机器人会？

押一个。先跑通一次，再改一张卡的顺序重跑对照。

第 2 题：程序跑偏了，最该先做哪一步？

押好后完成「送到目标再改卡重跑」任务。

第 3 题：「重复×2」后面紧跟「向前」。跑一遍时，「向前」会做一遍、连做两遍，还是被取消？

押好后加「重复×2」再加「向前」，点走一遍对照。

只改一张卡，后面全会走偏；先找第一处差异

指令一条接一条执行，没有「魔法跳过」。第 3 张转错了脸，后面所有「向前」都顺着错脸走，看起来像整条路坏了——其实第一处差异就在那一张。

左转、右转只改朝向，格子不动；向前才进一格。把「转」听成「走」，是最常见的走偏。

对照星星，圈出第一个分叉的步骤，只改那一张再跑。整叠重洗也许碰巧走到，但说不清是谁修好的。

尚未完成：先让海龟走到星星。

先读一遍卡片再走；转不走路，走才进格

舞台上只改一件事：指令条里的一张卡。同一只海龟、同一格起点、同一颗星星。先读完整排卡再点「走一遍」；走到星星以后，只改一张再走。这样比，才知道路偏了是因为那一张，不是海龟「不想听话」。

回家只带两句：「转不走路，走才进格」；「只改一张，先找第一处差异」。不要写成「卡片有魔法」或「整叠重洗才算调试」。

指令卡顺序

一张做完才做下一张。没有跳过中间的咒语，海龟也不会自己改路，要按条走完。

朝向独立

左转、右转只转脸，格子不动。向前才进一格。三张卡一步一步，不是同一种咒语。

网格模型

五乘五的格子让一步一效看得见。中间那块石头进不去，要绕开，不要拆墙。

调试找差异

对照星星，圈出第一个走偏的步骤。只改那一张再跑，一步一步调，不要整叠重洗。

迭代再跑

一次只换一张再跑。整叠重洗分不清是哪一张改对了，下次还得重找，不是咒语。

不安全路径红线

真人走路实验要清场地。不拿尖物当机器人，不奔跑追逐，大人看着，一步一步走。

  1. 读序列。口头把每张卡念一遍，再点「走一遍」。
  2. 找差异。对照星星，圈出第一个走偏的步骤。
  3. 改一条。只改那一张再跑，看路有没有被修好。
  4. 写完成句。转不走路；只改一张。划掉「整叠重洗」。
4–6 岁 · 一句话

卡片要一张一张按顺序做。转圈不是往前走。错了就找出哪一张不对，改一张再试。

7–9 岁

程序按顺序执行。左转只改朝向，向前才换格。第 3 张错，后面常常全偏。调试是找第一处差异，不是整叠重洗。

10–12 岁 · 进阶

「重复×2」把后面一张展开两次，是本页尺子，不是编程语言语法。条件、传感器、真机遥控另开一课。本页只练顺序与单变量修改。

这在教什么：孩子要能指着指令条说「只改一张、后面才会偏」，并先圈出第一处差异。完成看的是对照，不是背「程序」两个字。拒「重抽直到对」。

  • 左转以后，海龟进格了吗？
  • 路偏了，先圈哪一张？一次改几张？
  • 地上能堆积木当障碍练走吗？

只改一张卡，后面全会走偏；先找第一处差异

同一条指令条，只看改动的那一张。第 2 张本该左转却写成右转，海龟的脸从那儿就错了；后面所有「向前」都顺着错脸走，看起来像整条路坏了，其实第一处差异就在那一张。

家里也能看见同一家人。按食谱做饼干，漏掉「先预热」这一步，后面拌面、入炉都会怪烤箱；其实第一处差异在预热。搭积木说明书第 3 步装反，第 8 步对不上，也该先回到第 3 步，不要把整盒倒出来重来。

「重复×2」是加试，不是主任务：它把后面一张展开两次。单独一张重复没有用。条件判断、传感器、真遥控器，本页不覆盖。本页「重复×n 把后面一张展开 n 次」只是比较尺子，不是编程语言语法。

地上走路实验要清场：积木、电线、椅子腿都先拿开。不拿剪刀、铁丝当机器人。本页是格子上的海龟，不是真机遥控课。

差异点第一个

两套卡片从哪一步开始分叉，先圈出那一张。后面偏了常常是前面转错了脸。

第 n 步记录

写下「第 n 步起偏」，只改那一步再跑一遍。一次改三张，分不清是谁修好的。

预测三环

先写下「下一步会走到哪一格」，再点走一遍，最后对照卡片，指令一步一步对。

条件另开一课

「如果碰到石头就左转」是以后的课。本页只练按顺序一步一步走，没有传感器。

清场安全

地上留出走路空档。积木、电线、椅子腿先拿开，大人看着，一步一步走不奔跑。

n 步写在一起

纸上写「走 3 步」时，数字和「步」不要拆开，否则孩子会只看见 3，指令要写在一起。

对照：只改一张修好 · 整叠重洗 · 「卡片有魔法」

三列用同一只海龟、同一颗星星。只改一张卡。一次改两样，分不清到底是顺序错还是方向错。

只改一张：圈出第一处差异，路常常就被修好。整叠重洗：也许碰巧走到，但说不出哪一张在干活。「卡片有魔法」整列划掉：海龟只听顺序，不听心情。

随意口令是加试：大人喊「往那边走」没有固定语义，明天复现不了，找不到第一处差异。真机遥控另开一行：有传感器、延迟和急停，本页不覆盖。

只改一张能调试

顺序卡一步一效。圈出分叉那一张，改完再跑，能说清是谁修好的，不是咒语。

整叠重洗不算调试

全清掉再碰运气，下次还是不知道该改哪一张。调试是对照差异改一条。

魔法整列划掉

海龟不会因为「想听话」自己改路。顺序错了就走偏，把这句话当否决句。

真机另开一行

真机器人有传感器、延迟和急停。本页只是格子海龟一步一步走，不是编程证书。

混着跑禁

一边改卡一边喊口令，分不清海龟听的是哪一套。一次只改一张，一步一步对。

网格对照用

格子让你看见「这一步走到哪」。没有格子，第一处差异很难圈，指令要对着走。

回家只记「只改一张、先找第一处差异」，不记代码词

在纸上画一排空格当指令条。先写一套能到星星的卡，再故意把其中一张改错，旁边写下「第几张起偏」。两套并排，比背「调试」两个字有用。

口头只要两句：「转不走路，走才进格。」「只改一张，先找第一处差异。」有人说「整叠重洗才快」或「卡片有魔法」，让孩子指着被圈出来的那一张反驳。

若要在地上走，场地先清空，大人看着，不奔跑。海龟几何页用同一套「向前、左转」把图形画出来，可以接着去。本页不是编程语言课，也不连接真机器人。

3 轮单卡

同一颗星星做三轮。每轮只允许改一张卡，记下改前改后停在哪一格。

两句预测 / 结果

每轮先写「我猜它会停在哪」，走完再写「它停在哪」。差在哪一张？一步一步对。

清场大人看

地上走路要清场。不奔跑，不拿尖物当机器人。本页不是体能课，是一步一步指令。

海龟几何同一套动词

这里改方向，隔壁海龟几何用同一套「向前、左转」一步一步把图形画出来。

只改一纪律

一次只换一张，否则分不清是顺序错还是方向错。调试要能指着那一张。

目标对照

先指着星星说「要到这儿」，再回头圈出第一张走偏的卡。那就是一步一步调试。

怎样才算公平的一次比较

想知道「路偏了靠不靠那一张卡」，就只改一张。同一只海龟、同一格起点、同一颗星星，先走通一次，再只改一张重走。加「重复×2」、换成口头口令，是另一次对照，不要和「改哪一张」叠在同一档里讲。

  • 只改这一项：指令条里的一张卡（对 / 错，或左右转对调）。
  • 先保持不变：同一只海龟、同一格起点、同一朝向、同一颗星星。
  • 要观察的：它停在哪一格，从第几步开始和目标分叉。
  • 另开一行：同样送到星星，「重复×2 + 向前」是走一格还是两格。

还可以问下去

  1. 把「向前、左转、向前」改成「左转、向前、向前」，海龟还会踩到同一格吗？第一处差异在哪一张？
  2. 食谱漏了「先预热」，后面烤糊了。该把整本菜谱扔掉重买，还是先回到那一步？和本页像在哪？
  3. 「重复×2」后面紧跟「向前」，向前会做几遍？单独放一张重复、后面没有卡，海龟会动吗？

按年龄分层的讲法

同一个现象，三个年龄段讲到哪一层。建议只讲孩子当前那一层，讲完就停，不要把循环和条件提前塞进四岁耳朵。

给家长的问题

  • 海龟走偏时，孩子指的是「第几张卡」，还是在说「它不想听话」？让他再圈一次第一处差异。
  • 左转以后格子没动：哪一句四岁听得懂？试「转只是转脸，走才换格」。
  • 如果他一次改了三张，路碰巧对了——为什么这句不能当本页的完成句？差在「说不清是谁修好的」。
  • 整叠重洗和只改一张，哪边能复盘？食谱漏了预热，该扔书还是回到那一步？
  • 「重复×2 + 向前」会走几格？单独一张重复呢？本页能当编程语言课吗？
  • 地上走路实验的红线怎么说？积木、尖物、奔跑？本页格子海龟等于真机器人吗？

背后的原理

舞台上不写这些词，留给孩子用眼睛看。家长可以指着指令条讲：程序是按顺序执行的一串指令。向前改格子，左转、右转只改朝向。第 n 张错了，后面所有「向前」都顺着错脸走，所以看起来像整条路坏了——第一处差异往往就在那一张。

调试靠最小改动：对照目标，圈出第一个分叉点，只改那一张再跑。整叠重洗也许碰巧走到，但复盘不了。本页「重复×n 把后面一张展开 n 次」只是比较尺子，用来看见「同一张卡连做两遍」，不是编程语言语法，也没有条件判断。

朝向和位移要分开，是空间推理里最常见的卡点。口头乱喊「往那边」没有固定语义，明天复现不了。真机器人还有传感器、延迟和急停，本页不覆盖。

不插电把思维从屏幕上拿下来，但地上走路仍要清场。不拿尖物当机器人，不奔跑追逐。舞台是格子海龟示意，不是遥控课。
