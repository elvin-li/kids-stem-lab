这在教什么

这在教什么

球停在哪里，是被“高度”和“摩擦”一起决定的。放得越高，球到坡底时越快、滚得越远；跑道越粗糙，球停得越早。质量在这个模型里被约掉，所以换成更重的球，停的位置几乎不动。

  • 🪜 放得高 滚得更远
  • 🧶 跑道糙 早早停下
  • ⚖️ 换重球 停在同一处
  • 🔀 只改一项 才看得清
4–6 岁一句话版本

把球放高一点，它就会滚得更远。

7–9 岁再说清楚一点

球举得高的时候，身上存着一份“能滚的本钱”。放手以后，这份本钱会一点一点变成速度：越往下滚，球就越快。所以起点越高，到坡底时越快，冲出去也越远。

坡越陡，球在坡上加速得越猛，很快就冲到底；坡很平的时候，球慢慢溜，甚至可能停在坡上不动——因为摩擦把它抓住了。

平地上的跑道也在偷偷帮忙刹车。冰面几乎不刹车，球滑得很远；地毯刹得厉害，球没滚几步就停了。摩擦不是把速度弄丢了，而是把它变成了一点点热。

还有一件反直觉的事：把球换成更重的，它停的位置几乎不变。重的球本钱多，但也更难推动，两件事又抵消了。

10–12 岁进阶：能量转换与变量控制

球在高度 h 时具有重力势能 PE = m·g·h。下滚过程中它转成动能 KE = ½·m·v²，同时摩擦不断把一部分变成热 Q。能量总量不变，只是换了形式。

忽略摩擦时，坡底速度满足 ½·m·v² = m·g·h，两边的 m 可以约掉，得到 v = √(2·g·h)：坡底速度只由高度决定，跟球有多重无关，也跟坡有多陡无关。陡坡只是让球更快地到达坡底，不会让它到得更快（速度更大）。

冲上平地后，摩擦力做负功直到球停下，停止距离 d = v² / (2·μ·g)。这里 m 又被约掉了，所以换个更重的球，停的地方几乎一样。但如果球撞到墙上，重球的动能更大，撞击的效果完全不同——质量不影响“停在哪”，却影响“撞多狠”。

坡太平时球会卡住：当 tanθ ≤ μ 时，沿坡向下的重力分量小于静摩擦能提供的阻力，球保持不动。

要判断某一项的影响，必须做控制变量的对比：两轮之间只允许改动高度、角度、跑道或球重中的一项，其余保持不变。这一页的完成条件就是这样设计的。

势能一路换成动能和热

三条总长度一样——能量没有消失，只是从紫色换成蓝色，再换成橙色的热。

同样的高度，不同的坡

忽略摩擦时，两个球到坡底的速度一样快；陡坡只是让这件事发生得更早。

给家长的陪伴追问

  1. 让孩子先锁定预测并完成 A 轮。预测写错没关系——被自己的预测“打脸”才是最好的学习时刻。
  2. 提醒孩子在高度、角度、摩擦或质量中只改变一项，再锁定预测完成 B 轮。
  3. 追问：「改变的条件怎样影响停止距离？」文字反思可选，不影响完成。
  1. 指向变量：“这两轮你一共改了几样？如果改了两样，你怎么知道是哪一样起作用？”
  2. 逼近误解：“重的球是不是一定滚得更远？”让孩子先猜，再用球重滑块验证。这是本页最有价值的一次意外。
  3. 区分两件事：“重球和轻球停在同一个地方，那被哪个撞到更疼？”帮孩子把“停多远”和“撞多狠”分开。
  4. 追问摩擦：“球慢下来的时候，它的速度去哪了？”引导到“变成了热”，而不是“消失了”。
  5. 陡与快：“同样的高度换成更陡的坡，球到坡底会更快吗？”正确答案是速度一样、时间更短，这一点连大人也常混。

离屏延伸活动

  1. 书本斜坡：用一块木板垫在书上做斜坡，垫一本、三本、五本各放一次小球，用贴纸标记停的位置。
  2. 换跑道：同样的坡，让球分别滚到地板、毛巾和地毯上，比较三段距离。
  3. 大小球：找两个大小相同、重量不同的球（例如实心球和空心球）各滚一次，看看停的位置差多少。
  4. 找卡住的角度：慢慢降低斜坡，直到球再也不肯自己滚下来，记下这个角度——那就是摩擦刚好赢过重力的位置。

提示：不必要求孩子说出“势能”“动能”。能说出“放高一点本钱多”“地毯把它刹住了”“我只改了一样”，这一页的目标就达到了。

背后的原理

能量守恒。球在高处拥有重力势能 PE = m·g·h；下滚时变成动能 KE = ½·m·v²，摩擦做功变成热 Q = μ·m·g·cosθ·d。理想模型中 PE + KE + Q = m·g·h。能量不会消失，只会换一种形式。

高度决定“本钱”，角度决定“花多久”

在无摩擦的理想情形下，坡底速度只由下落高度决定：½mv² = mgh，得 v = √(2gh)，其中不含角度。换成更陡的坡，同一高度下到坡底的速度相同，只是路程更短、时间更少、平均加速度更大。孩子感觉“陡的更快”，指的通常是“更快到底”，而不是“到底时更快”。

加上摩擦后角度就有影响了：坡越陡，斜面上的路程越短，摩擦耗掉的能量 Q 越少，坡底速度反而略高。这也是本页里“只改角度”仍会改变停止距离的原因。

为什么质量不影响滑行距离

坡底满足 ½mv² = mgh − Q，平地停止距离 d = v² / (2·μ·g)；两式里的质量都被约掉，所以轻球和重球停在同一处。直觉上会觉得“重球更有劲”，但重球同时也更难被推动、压在地面上的摩擦力也更大，两者刚好抵消。

要注意区分两件事：停止距离与质量无关，但动能与质量成正比。同速度下质量加倍，动能加倍——所以撞击的破坏力会明显不同。孩子说“重球撞得更疼”是对的，只是这和“滚多远”是两个问题。

什么时候球根本不动

斜面上下滑趋势与静摩擦的比较给出临界条件：当 tanθ ≤ μ 时，静摩擦足以锁住球，它会停在坡上不动。把角度调到很小、跑道换成地毯时就能看到这种情况。

为什么必须一次只改一项

本页的完成条件要求两轮试车在高度、角度、跑道、球重四项中恰好有一项不同，且两轮都必须先锁定预测、球必须真正滚到停下（撞墙或卡在坡上的一轮不计入）。如果同时改了两项，停止距离的变化就无法归因，这次比较也就不能回答任何问题——这正是控制变量法的意义。

  1. 预测：质量加倍，停止距离会变吗？
  2. 观察：势能、动能和摩擦热怎样交换？总量有变化吗？
  3. 推理：同高度时，改变角度为何仍可能改变坡底速度？
  4. 迁移：要让球停得更远，你会优先调哪一项？为什么？

本模拟说明：使用固定步长 1/480 秒积分；把球当作沿斜面滑动的质点，用单一摩擦系数概括滚动与滑动阻力，未区分滚动摩擦、未计入空气阻力与球的转动惯量，因此数值只用于比较趋势，不代表真实测量值。
