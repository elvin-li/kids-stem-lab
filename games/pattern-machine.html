家长深读：两条量表在教什么

学习目标：第一条把「增长速度」变成一个能比长短的量。喂 1 到 5，加法机只长 4，乘法机长 8，平方机长 24 —— 孩子不用会算斜率，也能直接看出「乘的机器比加的机器长得快，平方机最猛」。这是后面斜率与二次增长的直觉底子。

下面两个圆点在说什么：加法机、乘法机、两步机、减法机每一步多的量都一样（差固定），所以点图连起来是直线；平方机和交替机每一步多的量自己在变，连起来就不是直线了。先看差，再猜规则，比乱试快得多。

第二条不是计分板：它只累加「认出过的机器种类」，猜错不扣、也不计时。要传达的是「猜错是收集线索的一部分」，而不是比谁快。

家长深读：猜机器规则在教什么

学习目标：从几个例子里提出一条能预测全部情况的规则，再用没用过的那一组去检验它。这就是归纳加验证，也是代数里「找关系式」的完整动作。

为什么给三组而不是两组：两组数据几乎总能被好几条规则同时满足。1→2、2→4 既可以是「×2」，也可以是「自己乘自己再…」的一堆变体。这里刻意保证：选错的那条规则一定会在第三组对不上，所以「再看看第三组」不是敷衍，而是真的能判出对错。

答错时的说法：页面只会指出你选的规则在哪一组算不上，不清零、不计时、不催。请把「对不上」当成好消息 —— 它排除了一条错路，这正是数学家找反例的做法。

给家长：这在教什么 · 一起追问 · 背后的原理

这在教什么：函数思维。上面三件套合起来是一条完整链路 —— 看进出 → 提出一条规则 → 用新数据检验。孩子会从「算出这一题的答案」慢慢转向「说清所有情况都怎么变」，这正是从算术迈进代数的那一步。

背后的原理

函数就是一种「稳定的对应关系」。六台机器都守着同一条底线：同一个数进去，永远得到同一个数。这个「稳定」才是函数的本质，而不是「有一条漂亮的算式」。要判断是不是函数，只问一句：同一个输入会不会给出两个不同的输出？会，就不是一台机器，是两台。生活里这样的对应关系很多 —— 价目表、身高体重表、自动售货机、快递单号查物流，都是「投进一个，出来一个确定的」。交替机没有一条整齐的公式，它仍然是函数；抽签盒有盒子有动作，却不是函数。

为什么要多组数据才能确定规则。只有「进 3 出 6」这一组，加法机和乘法机都成立；两组也常常分不开。三组之所以管用，是因为每多一组就能排除一批候选 —— ③里的干扰项都刻意选成「一定会在第三组对不上」，所以「再看看第三组」是真能判出对错的动作，不是敷衍。同时要跟孩子说清另一半：例子再多也只是还没被推翻，不等于被证明。真正确定规则要靠一句一般化的说法（「输出 = 2 × 输入 + 1」），不是靠例子的数量。这也是「喂 0 进去」特别值钱的原因：a × 0 + b = b，一次就把加数暴露出来，再喂 1 就能算出乘数。

逆运算的意义。机器往前走是「进 → 出」，倒着走是「出 → 进」，用的正好是相反的运算：加法机倒回去要减，乘法机倒回去要除；两步机倒回去要先减 1 再除以 2 —— 连顺序都得反过来。这就是解方程的全部动作：把 2x+1=7 里的「+1」和「×2」依次撤销。玩法很简单：家长报一个出来的数，让孩子猜进去的是几。他做到了，就是在没有符号的情况下解了一次方程。减法机还顺手带出负数：3 进去出 −1，想倒回去必须加 4。

一起追问：给家长的问题

  1. 「你怎么知道规则是这个？再给它一个没试过的数，还成立吗？」—— 把「猜对了」和「检验过了」分开。
  2. 「如果喂 0 进去会出来什么？先说出来，再动手试。」—— 先预测再验证，比直接看答案有用得多。
  3. 「我告诉你出来的是 7，你能倒回去猜进去的是几吗？」—— 这就是逆运算，也是解方程的第一步。
  4. 「前三个都对，就一定说明规则对吗？找一个前面都对、后面不对的例子。」—— 有限样本不能唯一确定规则。
  5. 「2、4、8、16 下一个一定是 32 吗？每次加的数自己也在变，会走出另一条路。」—— 候选可以有两条。
  6. 「把这条规律用拍手、跺脚再做一遍。还对得上吗？」—— 抓的是规则，不是颜色装饰。

常见误区

  • 看到两个数就断定规则孩子看到 1→2、2→4 会立刻喊「×2」，可 x×x 之类的规则同样成立。别宣布他错了，追一句「再来一组看看」，让不够用这件事自己浮出来。
  • 把「有公式」当成函数的定义能不能写成算式和是不是函数是两件事。判断标准只有一条：同一个输入是否总给同一个输出。
  • 急着上符号先让孩子用「进去的数」「出来的数」把话说顺，再换成 x 和 y。符号是省事的记法，不是理解的入口。
  • 答错就换一题对不上的那一组是全场最有价值的信息。留在原题上问「它在第几组对不上」，收获比换新题大得多。

加几等差

每一步都加上同一个数，才叫这条规则；改一次加几，后面全变。不是数字碰巧变大。

乘几更陡

每一步都乘同一个数，才会越来越陡；不是随便把数字变大好看。单看一组不够定。

轮换形状色

形状或颜色按固定顺序循环，重复那一段才叫图案；改一条，花就变。好看不算。

新出来的一项对不上，就换规则；只看前面好看，还不算验证过。下一格也要对上。

怎样才算公平的一次比较

想知道「前三项对了是不是规则就对」，就只改候选规则这一项。同一串开头，先按「每次加 2」往下写，再按「每次乘 2」往下写。不要同时换材料、换颜色，那是另一次对照。

  • 只改这一项：你猜的那条规则（加几 / 乘几 / 轮换）。
  • 先保持不变：已经看见的那几项。
  • 要观察的：下一项或一个没试过的输入，还对得上吗。
  • 另开一行：用拍手、积木重摆同一条规律，看他抓的是规则还是颜色。

给家长：规律为什么是数学的第一块地基

规律（pattern）不是幼儿数学里的“花样活动”，而是代数思维的真正起点。孩子说出“接下来是草莓”的那一刻，他已经在做归纳推理：从有限的几个例子里提取出一条能预测未来的规则。

三个能力层次，请按顺序走。主流幼儿数学课程（NCTM 的 Algebra 标准、英国 EYFS、新加坡 CPA）都把规律分成同样的阶梯：识别（看出这里有规律）→ 复制（照着摆一遍）→ 延续（往后接）→ 补缺（中间少了什么）→ 创造（自己造一个）→ 迁移（用不同材料表达同一条规律）。最后那一步最关键，也最常被跳过。

“重复单元”是核心概念。孩子常靠“上一个是红的所以这个是蓝的”这种局部配对蒙对，看起来会了，其实没抓住整体。判断他是否真懂，只需问一句：“重复的那一小段是什么？”能圈出 🍓🍌 这一段，才算掌握了单元。本页在队伍里画了虚线分隔，就是为了让单元看得见。

规律有两大家族。一类是重复规律（🍓🍌🍓🍌…），单元循环出现，对应后面的周期、倍数、余数。另一类是生长规律（1、3、5、7…），每一步按固定量增加，对应数列、函数和一次关系。四五岁先玩重复，能数到 10 之后再进生长——本页的“越来越多”就是生长规律的入门版。

迁移测试比正确率更能说明问题。孩子摆出 🔴🔷🔴🔷 之后，请他用完全不同的材料表达同一条规律——拍手/跺脚、蹲下/站起、勺子/叉子都行。能做到，说明他掌握的是抽象结构“AB 交替”，而不是记住了两个具体图形。这一步在研究文献里叫 pattern generalization，是从具体走向抽象的分水岭。

“找不对的一块”练的是另一种能力。延续规律只需要往前看，而挑错需要拿整体去检验每一处——这正是数学证明里“找反例”的雏形。孩子说“这里应该是兔子，怎么是老虎”，他就在做验证，而不只是模仿。

说错的时候不要直接纠正。更有效的回应是把他的答案接着摆下去，让矛盾自己暴露：“好，我们就照你说的放老虎，那再往后是什么？……咦，跟前面那一段不一样了？”让孩子自己发现冲突，比被告知答案记得牢得多，这就是 productive struggle。

按年龄分层：同一个页面能玩很多年

4–6 岁看得见、摸得着的重复

目标：认出重复单元，能延续 2~3 个，并且自己造一条。这个年龄段不需要任何符号或算式，全部用图形、动作和声音完成。

本页玩「接着排」的“两个换”和“成双”，以及「我来造规律」。“三个换”（ABC）对四岁偏难，孩子熟练之后再解锁。

怎么问：「重复的那一小段是什么？」「接下来该谁了？」「你能用拍手把这个规律做出来吗？」不要问“为什么”，四五岁还很难用语言解释结构。

过关标准：能用积木/贝壳/餐具把屏幕上的规律换一种材料重摆一遍。

7–9 岁从图形规律走到数字规律

目标：把“每次多几个”说成数，会用“差”这个概念，能预测第 10 层而不必一层层画出来。

本页玩「越来越多」，再打开家长模式下的「生长图形」：数第 N 个图形有几块。关键提问是「能不能不画出来就知道？」——这一问把孩子从数数推向计算。

也可以开始玩「猜规则」的加减法和乘法档。喂 0 进去是最有用的一招，因为它直接暴露加数。

过关标准：能填出 2、5、8、11 的下一项并说明“每次加 3”；能指出 1、4、9、16 的差在变。

10–12 岁规则、变量与反例

目标：用一句一般化的语句描述所有情况（“第 N 层有 2N−1 个”），并理解符合前几项不等于规则正确。

本页玩「猜规则」的两步和挑战档，再做正式任务里的反例检验。核心体验是：1、2、4 之后可以是 8（翻倍），也可以是 7（每次多的量加 1）——有限的数据不能唯一确定规则。这一课比任何公式都重要。

可以引入变量写法：把“每次多 4 块，开头 1 块”写成 4N−3，再代入 N=1 检查。差固定 → 一次关系；差本身在变 → 二次关系。

过关标准：能给出一条“前三项都符合但第四项不符合”的假规则，也就是自己造一个反例。

离屏延伸：不用任何设备也能玩

  • 餐桌串串用勺子和叉子交替摆一排，问孩子下一个放什么。换成两颗葡萄一颗草莓，就变成 AAB。
  • 身体规律拍手、拍腿、拍手、拍腿……让孩子接下去。再问：能不能用积木把这个规律“画”出来？
  • 散步找规律人行道砖、栏杆、地砖花纹、斑马线。问“重复的一段有多长”，比问“这是什么规律”更好回答。
  • 楼梯数列上楼时每级台阶放 1、2、3 颗小石子，问第 5 级要放几颗。这就是生长规律的实物版。
  • 穿珠子给一条“红蓝蓝红蓝蓝”的开头，让孩子接着穿完。穿错了不要拆，让他自己对照开头找。
  • 故意出错家长摆一排，故意放错一个，让孩子当检查员。角色一换，孩子的注意力会明显提高。

常见误区

  • 只练延续，不练创造能接下去不代表理解结构。让孩子自己造一条并说出重复单元，才是真掌握。
  • 过早上数字四五岁用图形和动作，效果远好于数字卡片。数字是后来的表示法，不是起点。
  • 把颜色当唯一维度规律可以按形状、大小、方向（↑↑↓）、数量、声音来做。多换维度，抽象能力才长得出来。
  • 急着报答案孩子卡住时先问“重复的一段是什么”，再把他的错答案接着摆下去让矛盾自己出现。

背后的原理

规律是一条能拿新数据去检验的规则，不是把队伍摆好看。颜色、排队、装饰可以换材料重做；对不上的那一项，才说明这条规则该丢掉。

一台机器就是一个 function：每喂一个数，它只会吐出一个确定的结果。 孩子在这里做的事，数学上叫「根据有限的样本推断规则」—— 先观察、再猜想、然后用新数据验证。这跟科学家的工作方式是同一套。

日记里的「差」那一列是关键。如果每行的差都一样（比如都是 3）， 规则里的乘数就是 3，这叫一次关系 linear； 差本身也在变（1、3、5、7…），就说明藏着平方，是二次 quadratic。 先看差，再猜规则，比乱试快得多。

「喂 0 进去」是最有用的一招。因为 a×0 + b = b， 输出会直接把加数 b 暴露出来。剩下的只要再喂 1， 就能算出乘数。这种「挑一个能让干扰项消失的输入」，是解方程的核心直觉。

生长图形模式把同一件事换成了看得见的版本。数第 N 个图形有几块， 孩子可以一块块数（算术），也可以发现「每次多 4 块，所以是 4N 加上开头那几块」 （代数）。同一个答案，两条路——后一条路才是能走远的那条。

还可以问下去

  • 前三个数都对，就一定说明你猜的规律是对的吗？试着找一个「前面都对、后面不对」的例子。
  • 2、4、8、16…… 下一个一定是 32 吗？还有别的说得通的答案吗？
  • 日历上一个星期占一行。为什么同一列的日子，相差总是 7？
  • 自己编一条规律，让大人只看三组数来猜。他猜对了吗？你是怎么骗到他的？
