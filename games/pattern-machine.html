背后的原理

一台机器就是一个 function：每喂一个数，它只会吐出一个确定的结果。 孩子在这里做的事，数学上叫「根据有限的样本推断规则」—— 先观察、再猜想、然后用新数据验证。这跟科学家的工作方式是同一套。

日记里的「差」那一列是关键。如果每行的差都一样（比如都是 3）， 规则里的乘数就是 3，这叫一次关系 linear； 差本身也在变（1、3、5、7…），就说明藏着平方，是二次 quadratic。 先看差，再猜规则，比乱试快得多。

「喂 0 进去」是最有用的一招。因为 a×0 + b = b， 输出会直接把加数 b 暴露出来。剩下的只要再喂 1， 就能算出乘数。这种「挑一个能让干扰项消失的输入」，是解方程的核心直觉。

生长图形模式把同一件事换成了看得见的版本。数第 N 个图形有几块， 孩子可以一块块数（算术），也可以发现「每次多 4 块，所以是 4N 加上开头那几块」 （代数）。同一个答案，两条路——后一条路才是能走远的那条。
