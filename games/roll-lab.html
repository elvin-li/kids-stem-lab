滚动比滑动省；圆的会滚，球没有脾气

摊开时，一大片肚皮贴着地，走一步就要拖擦一大片。蜷成圆球，贴地的变成一条细线，滚动通常更省。这不是球有脾气，是形状从扁变成圆。

滚动不是永动机：轴上还有摩擦，泥地会塌陷，软地毯会把圆按出坑，阻力又上来。雪橇是滑动家族，轮子是滚动家族。本页先交「先要圆」。

西瓜虫受惊也会蜷成球，靠体节之间的膜。门要开，得有一条铰链缝。龟壳与肋骨愈合，保护好、蜷不成这种球。策略不同。

远观不抓活体。模型轻推。不要真把人卷进硬筒。

滚比滑省线对上片

圆的贴地是细线，摊开是一大片。滚动通常比滑动省，不是完全没阻力。

不是永动还有摩擦

轴摩擦和地面塌陷仍吃能量。滚动省，不是永动机，软地毯还会把圆按出坑。

西瓜虫活蜷

西瓜虫也会蜷成球，靠体节之间的膜。远远看着就好，不要抓起来玩，接触点同样在换。

门铰一条缝

门要有铰链才能开；焊死成一块，门就开不了。缝是许可，不是魔法缩骨。

龟壳愈合

龟壳黏在骨头上愈合成一块，蜷不成这种圆球。策略不同，不是它不够努力。

活体禁

活的动物不要翻来翻去，只用模型轻轻推。不要把人卷进硬筒，圆了才会换接触点。

三列用同一排骨板。先只改铰链条数。一次改两样，分不清到底是谁让它成不了球。

8 条：能成圆球，滚动比滑动省。0 条：摊平，上限 0，卡在石块上。「球有脾气」和「不够努力」整列划掉：想蜷改不了零件，圆了才会滚。

想蜷调到 0 是加试：零件在，不想蜷也不会成球。本页百分比是比较尺子，不是体检表。

8 条成球会滚

八条缝都在，才能包成圆球。圆了才滚得走，滚动摩擦通常小于滑动摩擦。

0 条卡住

一条缝都没有，摊开贴地，滚动变成滑动，边角卡在石块上，接触点换不成。

球有脾气划掉

球没有脾气。圆了接触点才换，才会滚，不是它想滚，也不是它比较聪明。

努力否决

「它不够努力所以摊平」不对：没有缝就蜷不成，接触点换不了一圈。乌龟壳零件不同。

怎样才算公平的一次比较

想知道「成球靠不靠铰链」，就只改条数这一项。同一排骨板、同样想蜷，先 8 条试一次，再 0 条试一次。改「想蜷」是另一次对照，不要和「抽缝」叠在同一档里讲。

  • 只改这一项：铰链条数（8 条 / 0 条）。
  • 先保持不变：同一排骨板、想蜷先保持高。
  • 要观察的：成球没有，圆了能不能滚，摊开有没有卡住。
  • 另开一行：8 条铰链、想蜷调到 0，还会不会成球。

背后的原理

舞台上不写这些词，留给孩子用眼睛看。家长可以指着图讲：骨板之间要有够多的铰链，身子才能蜷成球。成了圆球，贴地从一大片变成近似一条线，滚动通常比摊开滑动更省，才滚得过空地。摊开时边角卡在石块上，滚不动。

本页「上限%=铰链条数×12.5；实际=min(想蜷,上限)；成球⇔实际≥80」只是比较尺子，用来让孩子看见「有缝才成球」，不是犰狳体检，也不是昆虫解剖。

滚动不是永动机：轴摩擦、地面塌陷、软地毯形变仍吃能量。球没有脾气，也不会自己决定要滚——是形状从扁变成圆。光想蜷、没有缝，还是一条硬壳。

乌龟壳黏在骨头上，蜷不成这种球。不抓活体，模型轻推。不要把人卷进硬筒。

0 条缝上限 0%，再想蜷也成不了球。圆了才会滚，滚动比滑动省。球没有脾气。铰链是几何许可，不是魔法缩骨。不抓活体。
