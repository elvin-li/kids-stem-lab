近远各拍一次，再同距换介质比谁先回来

舞台上先只改墙有多远：近处拍一次，听回声很快；远处拍一次，听等待变长。然后墙停在远处，只换介质，看水是不是最先回来。这样比，才知道回声是来回路程，不是墙在说话。

回家只带两句：「去一趟再回一趟」；「墙越远等得越久；同一堵墙，水更快」。不要只写「有回声」。

直达先到

掌声自己先到耳朵，这一下还没碰到墙，不算回声。回声要多走一趟回来。

回声来回

回声是同一类声跑出去再弹回来，去一趟还要加回一趟，不是新声音。

更远更久等

墙越远，来回路越长，第二下就要多等一会儿。仍是你那一声折返，听得清。

水最快

同一堵墙，水里声速最大，回声会最先折回来。测的仍是来回这一条，不是山谷会说话。

氦居中

氦气比空气跑得快、比水慢，同距回来夹在中间。仍是同一声折返，不是新声。

马路禁

不要站到车道中间拍手试回声，路边空地再试。井沿也不要失足喊，不是山谷会说话。

  1. 近处拍。记下等待短，像紧跟着的第二下。
  2. 远处拍。记下等待变长，路更长要多等。
  3. 换介质。同一堵远墙，比水、氦、空气谁先回。
  4. 写完成句。去一趟再回一趟。划掉「墙在说话」。

回声是来回，不是墙在说话

同一声拍手，先只改墙有多远。声波跑出去撞到硬壁再折返，去一趟加回一趟。墙越远，路越长，等得越久。太近会和掌声叠成一下，听不清第二下。

蝙蝠发出再听回，测的也是来回。本页拍手是慢动作版。声呐、井口、空教室、山壁，都是同一家人。沙发、窗帘这类软东西会把声音吃掉，几乎没有回声。

山谷一声变几声，是好多面墙各回一次，不是声音自己复制。雷声滚是云层多次反射加距离，邻居账，另开一课。同一堵墙换介质：水最快，氦气居中，空气最慢。

护耳，不对着耳朵猛拍。不在马路中间、不在井沿失足处试。大喊勿扰人。本页秒数不是声呐手册。

山谷多次反射

雷声另开

雷声滚是云层多次反射，比拍手回声更复杂，另开一课，不要写进本页。

车道禁

车道中间不试回声，请到路边空地再拍手；井沿也不要探身大喊，不是山谷会说话。

对照：近处等得短 · 远处等得长 · 「墙在说话」

三列用同一声拍手。先只改墙远近，介质先固定。一次改两样，分不清到底是路长了还是介质变了。

近：等待短，像紧跟着的第二下。远：等待长。「墙在说话」和「只说有回声」整列划掉：要说出来回和快慢。

同距换介质是加试：水最快，氦居中，空气最慢。本页 t ≈ 2d / v 用来比较方向，不是声呐操作手册。

近短等

墙近时来回路短，回声很快回来，像紧跟着的第二下；再近就会叠在一起。

远长等

墙远时来回路更长，第二下要多等一会儿才回来，仍听得清是同一声。

有回声不够

只说「有回声」不够，要说出去一趟再回一趟。听的是反射回来的同一类声。

完成句去一趟回一趟

回声是去一趟再回一趟；水里也是来回，只是更快。墙太近会叠得听不清。

回家只记「来回」，不记声呐口令

在纸上画近、远两行，再加空气、水、氦三行。每行写等待谁短、谁长。五行并排，比背公式有用。有人说「墙自己会说话」，让孩子指着来回那一行反驳。

口头只要两句：「去一趟再回一趟。」「墙越远等得越久；同一堵墙，水更快。」蝙蝠若要写，另开一行：它测的也是来回，不是魔法。

护耳，不对着耳朵猛拍。不在车道中间试，不在井沿失足处喊。本页秒数不要抄成声呐手册。

五行距+介质

近、远各写一行等待，再加空气、水、氦三行比快慢。比的是来回，不是新声。

口令来回

回家说得出：回声不是一下，是去一趟再回一趟。墙太近会叠得听不清。

蝙蝠另开

蝙蝠测的也是来回，另开一行，不要抢本页完成句，也不是山谷在指路。

马路禁

不站车道中间试回声，井沿也不要失足大喊。空地拍一下，听第二下就够。

怎样才算公平的一次比较

想知道「等得久靠不靠墙远」，就先只改距离这一项。同一声拍手、同一种介质，先近处拍一次，再远处拍一次。换空气、水、氦气，是另一次对照，不要和「拉远墙」叠在同一档里讲。

  • 只改这一项：墙有多远（近 / 远）。
  • 先保持不变：同一声拍手、先用空气。
  • 要观察的：等待短还是长，波什么时候折回来。
  • 另开一行：同一堵远墙，空气、水、氦气谁先回来。

背后的原理

舞台上不写这些词，留给孩子用眼睛看。家长可以指着图讲：回声不是墙在说话，是声波跑出去撞到硬壁再折返。去一趟加回一趟，路越长等得越久。

本页「t ≈ 2d / v，空气约 340、氦约 1000、水约 1480」只是比较尺子，用来看见「更远更晚、水最快、氦居中、空气最慢」，不是声呐操作手册，也不是精确气温表。

近距时延小于听觉分辨，回声与直达叠在一起，听不清第二下。蝙蝠和声呐测的也是来回。山谷一声变几声，是好多面墙各回一次，不是声音自己复制。

护耳，不对着耳朵猛拍。不在车道试，不在井沿失足处喊。舞台可关声音只看波。
